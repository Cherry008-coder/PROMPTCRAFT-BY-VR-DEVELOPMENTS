        How 3-Key Failover Works
        
        
          
          
        • Try Key 1 → If rate limit / error / invalid, automatically tries Key 2
          • 
          
        • Try Key 2 → If fails, tries Key 3
          • 
          
        • Try Key 3 → If all fail, falls back to local engine (still generates 90+ prompts)
          • 
          
        • Keys are tried in order, with 1.2s delay between retries to avoid hammering
          •
